# Minimal Darwin runtime provider

This fixture contains two repository-owned Mach-O files generated by
`wintosh_dyld_smoke.exe --emit-runtime <directory>`:

- `libSystem.B.dylib` exports the harmless `_libSystemInit` test symbol.
- `RuntimeClient.macho` imports and calls that symbol through
  `@loader_path/libSystem.B.dylib`.

The provider is deliberately not Apple's `libSystem`; it is a small Wintosh
test provider used to prove DylibGraph resolution, mapping, binding and an
actual cross-image call.  No Apple binary or SDK is included.
