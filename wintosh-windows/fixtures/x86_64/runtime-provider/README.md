# Minimal Darwin runtime provider

This fixture contains three repository-owned Mach-O files generated by
`wintosh_dyld_smoke.exe --emit-runtime <directory>`:

- `libSystem.B.dylib` exports the harmless `_libSystemInit` test symbol.
- `libsystem_platform.dylib` is a second provider in the dependency chain.
- `libSystem.B.dylib` depends on `libsystem_platform.dylib` through
  `@loader_path`.
- `RuntimeClient.macho` imports and calls that symbol through
  `@loader_path/libSystem.B.dylib`.

The provider is deliberately not Apple's `libSystem`; it is a small Wintosh
test provider used to prove DylibGraph resolution, mapping, binding and an
actual cross-image call.  No Apple binary or SDK is included.

## Provenance and license

All three binaries are generated from the GPL-3.0-only test generator in
`wintosh-windows/tests/dyld_smoke.cpp`. They are repository-owned test
artifacts and are not derived from Apple's `libSystem`, `libplatform`, XNU,
Darling binaries, or any proprietary SDK. The Apple names are used only to
exercise Darwin install-name and dependency conventions; they do not imply
Apple origin or compatibility.
