# Source checkout manifest

This manifest lists every external checkout used locally beside the port.
These checkouts are deliberately excluded from the public Wintosh repository;
the upstream links below are the canonical way to obtain them. Their local
presence does not mean that code was copied into the Windows adapter or
cleared for redistribution.

## Native overlay inventory

The published `wintosh-windows` overlay contains 83 source/header, CMake, and
smoke-test files. A matching local comparison copy may exist at
`darling-source/src/native/windows`, but the implementation area in the public
repository is `wintosh-windows`; the complete Darling source remains upstream.
The exact file list is generated by the directory itself and the current
family-level status is maintained in `PRIMITIVE-MATRIX.csv`.

## License review rule

If a future commit copies code from a reference checkout, add its exact source
path, upstream commit, copyright, license text, and test gate to the matrices
before merging the code. A missing root license is an unresolved review item,
not permission to use the code.
