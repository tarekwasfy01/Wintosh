## Native overlay inventory

`darling-source/src/native/windows` currently contains 83 source/header,
CMake, and smoke-test files. The overlay is the implementation area; the
external checkout directories above are not silently folded into its license.
The exact file list is generated by the directory itself and the current
family-level status is maintained in `PRIMITIVE-MATRIX.csv`.

## License review rule

If a future commit copies code from a reference checkout, add its exact source
path, upstream commit, copyright, license text, and test gate to the matrices
before merging the code. A missing root license is an unresolved review item,
not permission to use the code.
