# Wintosh Darwin TLV provider fixture

This directory contains a repository-owned Mach-O dylib generated by
`wintosh_dyld_smoke.exe --emit-tlv`.  It contains the four Darwin TLS section
families used by the native loader:

- `__thread_data`
- `__thread_bss`
- `__thread_vars`
- `__thread_ptrs`

The fixture contains no Apple source, SDK, system library, or Apple binary.
It exists to exercise section mapping and Darwin-TLV initialization on
Windows.  Its generator is GPL-3.0-only and is covered by the repository
license files and source manifest.

Regenerate it with:

```powershell
& .\build-windows-current\Release\wintosh_dyld_smoke.exe `
  --emit-tlv .\wintosh-windows\fixtures\x86_64\tlv-provider
```

Inspect it with:

```powershell
& .\build-windows-current\Release\wintosh.exe `
  --inspect .\wintosh-windows\fixtures\x86_64\tlv-provider\libwintosh_tlv.dylib
```

This is a loader fixture, not proof that arbitrary Apple `libpthread` or
Apple TLS code can already run.
