# Wintosh x86_64 Mach-O fixtures

`minimal-exit.macho` is a small, reproducible x86_64 Mach-O executable used by
the native Windows runner tests.  It contains a `LC_MAIN` entry point and one
dyld binding for `_exit`; the entry code exits with status `23`.

The fixture is generated by the GPL-3.0-licensed Wintosh test source
`../tests/macho_exit_smoke.cpp` using:

```text
wintosh_macho_exit_smoke.exe --emit minimal-exit.macho
```

It contains no Apple SDK, macOS system library, proprietary Apple code, or
third-party binary.  It is therefore suitable as a repository-owned loader
fixture, but it is not a real macOS application and does not prove framework
compatibility.
